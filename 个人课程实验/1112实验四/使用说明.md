# 任务二  鲁迅与周作人杂文的文本特征对比

Word 报告包含语料说明、TF-IDF 前十词表、主题表、条形图、词云、11 条原文抽查和结果解释。附录列出 15 组同年配对的文章与出处。两张图可从「图表」单独取用。彩色词云各展示平均 TF-IDF 排名前 42 的词，字形和排版由「词云.py」生成。

「复现材料」包括完整分析正文、原文链接和正文汉字数（语料.json），同年配对及体裁筛选记录（选篇记录.json），手工停用词及专名表（分词规则.json），逐篇分词和全部词项权重（结果.json），以及逐条证据（原文抽查.json）。

语料依据[维基文库《华盖集》](https://zh.wikisource.org/wiki/華蓋集)、[维基文库《华盖集续编》](https://zh.wikisource.org/wiki/華蓋集續編)和[虚阁网《谈虎集》](https://www.xuges.com/xdmj/zzr/thj/index.htm)的数字转录。文中段号对应语料文件中 `body` 的顺序，短摘采用该文件的简体字形。表中年份是可核查的写作或发表年份，两组的日期依据见报告。

## 运行

在「复现材料」中使用 Python 3.14。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python 分析.py
```

默认输出到「复跑结果」。用 `--font "字体文件路径"` 可指定支持简体中文的字体。Windows 用 `.venv\Scripts\python.exe` 调用虚拟环境的 Python。使用相同依赖与字体时，两张图的布局可以复现。
