# 苏大期刊层级网络的空间分布

[空间人文 GIS 作业](苏大期刊层级网络_空间人文GIS作业.html)包含「空间图谱」「原六圈层」和「实验说明与发现」。空间图谱在原有学科和期刊等级的基础上增加地理位置。点表示省级登记地的代表城市或境外机构所在城市，线表示苏大目录收录关系，线宽随收录条目数增加，面用 5° 或 10° 经纬格网汇总条目数。第 6、7 章知识点、定位依据和结果解释见「实验说明与发现」。

原图的 889 条记录中，609 条已定位，280 条保留在「待定位」清单。境外另选 3 本期刊，用于展示城市尺度的定位方法。国内按省级登记地聚合，例如江苏条目统一显示在南京代表点。

## 运行与查看

用 Chrome 打开「苏大期刊层级网络_空间人文GIS作业.html」。图谱可离线查看，打开期刊官网和定位依据需要联网。

1. 在「空间图谱」中切换「国内」「境外」「全球对照」或「待定位」。也可以按目录、圈层、学科筛选，或直接搜索刊名。
2. 点击地图上的地点，符合当前筛选的刊名会围绕该点成环。期刊较多时，点「上一组」「下一组」翻看，或点「全部展开」后放大、拖动查看。点刊名可打开右侧明细，点圆心或「返回地图」可收起刊名环。
3. 用「点」「线」「面」开关查看不同图层。要复现说明中的格网对比，在「国内」视图选择「苏大目录」，分别查看 5° 和 10° 格网。

## 导出

页面下方的「导出点 GeoJSON」「导出线 GeoJSON」「导出面 GeoJSON」分别生成可导入 QGIS 的三个图层。坐标使用 WGS 84，顺序为经度、纬度。也可导出当前记录的 CSV。导出内容随当前范围和筛选变化，导出前可用「清除筛选」恢复所选范围内的全部记录。

## 优化建议与操作步骤

现有版本已提供原六圈层、空间点线面和按地点展开的刊名环，也能导出当前筛选结果。下一步先解决两个具体问题：同一个地图点里的期刊究竟定位到了哪一级，以及地图、名单和导出表能否用同一批记录互相核对。以下是后续实施方案。

### 1. 补齐定位依据，分批把省级代表点细化到城市

**改进目标。** 目前江苏的苏大目录记录共 32 条，均落在南京代表点上。这能呈现省级登记分布，城市分布还需要逐刊核验。另有 280 条未定位记录，可以先从图书馆、情报与文献学门类入手，跑通查证和录入流程。

**操作步骤**

1. 在「国内」选择「苏大目录」，点击江苏点并导出 CSV，保留当前 32 条作为基线。另从「待定位」按学科导出核查清单。为每条记录保留原有 ID、刊名、原始刊号和目录来源，后续用 ID 回填结果。
2. 先选《苏州大学学报（法学版）》和《南京大学学报（哲学·人文科学·社会科学）》试查。用刊名和 CN 或 ISSN 确认具体版本，再查期刊官网的编辑部联系页、版权页等，分别记录「登记省份」「编辑部所在城市」「定位依据」「核验日期」。遇到主办单位与编辑部异地、资料过期或地址互相矛盾时，把两份信息和出处一并记下，暂留待核。
3. 依据核验结果设置「城市已核验」「省级代表点」「待定位」三种状态。城市已确认的用对应城市代表点绘制，省级记录继续用原代表点，待定位记录保留在清单中。详情卡与点图层导出同时提供定位状态、坐标精度和来源链接。省级统计按登记省份汇总，城市视图按已核验的编辑部城市汇总。

**验收办法。** 抽查同名异版、只有省级信息和地址有冲突的记录各一条。只细化这 32 条已有坐标的江苏记录时，江苏登记地总数应保持 32 条。城市视图则显示已核验条数，其余条目仍能在省级视图查到。每补一批待定位记录，单独记录补查前后的覆盖率和仍缺的证据，便于对账。

### 2. 改善检索和刊名环，统一筛选与导出口径

**改进目标。** 现有搜索按刊名匹配。后续补充按刊号和曾用名查找，并让用户从搜索结果直接跳到目标刊，减少在北京等多期刊点位逐组翻看的次数。

**操作步骤**

1. 将原始刊名、规范化刊名、CN、ISSN 和曾用名放入检索索引。刊号类型按资料分别填写，沿用原图的原始字段值供复核。检索时统一全半角括号、空格和连接符，界面仍显示原始刊名。对重名或同刊不同版本的结果，用刊号、学科和目录来源让使用者选择。
2. 点选搜索结果后，根据记录 ID 找到对应点位，自动展开刊名环并定位到该刊所在组，同时在右侧打开明细。没有位置的记录可以直接看刊号与出处，并显示「待定位」。用键盘或手机浏览时，保留可点击的结果列表作为查刊入口。
3. 把目录、圈层、学科、关键词和地点组合成同一组筛选条件，让地图点、刊名环、地区统计和 CSV 共用筛选结果。地区统计增加省级排序，标明「已定位／当前筛选总数」，并提供进入待定位清单的入口。

**验收办法。** 分别输入「外国语（上海外国语大学学报）」和 `31-1038/H`，检查能否定位到同一条记录。再进入「国内」，选择「苏大目录」并点击江苏点，核对地点条数、刊名环合计及 CSV 数据行数。按当前数据，三处均应对应 32 条。

### 3. 把地区汇总和格网比较做成可以复查的分析

**改进目标。** 地图适合看空间分布，地区表适合读具体数量。将二者并置，可以看清某个格网为何颜色较深，也能直观看到同一批期刊换一种空间单元后怎样分组。

**操作步骤**

1. 在地区统计旁增加「省级地区」「四大地区」「经纬格网」三种汇总方式。表中列出地区名称、当前条目数、占已定位记录的比例，以及汇总范围。点击表中的地区或格网，地图和刊物名单随之选中。
2. 对比 5° 和 10° 格网时，固定目录、学科、圈层和坐标定位口径。记录非空格数量、最大格条数及其汇入的省份。图例注明色深表示每格条目数，比例的分母统一使用当前筛选下已定位的记录数。
3. 导出两套格网 GeoJSON，在 QGIS 中各作为一个面图层打开。依次核对格网大小、最大格记录和属性表条数总和。若将来开展单位面积的密度分析，再使用等积投影和明确的面积分母。

**验收办法。** 固定「国内 → 苏大目录」且清除地点选择，用现有 606 条记录复查：5° 格网有 21 个非空格，最大格 289 条；10° 格网有 9 个非空格，最大格 375 条。两个格网图层的条目数加总均应为 606。由此可说明聚合尺度对地图显示的影响。

### 4. 按任务补充期刊详情和目录版本

**改进目标。** 教师和学生查刊时需要投稿和核对信息，人文社科处需要知道某项认定适用哪个版本。可以共用期刊档案，再按任务显示不同字段。

**操作步骤**

1. 先用图情档期刊做小样本，在详情卡增加收稿范围、主办单位、期刊官网、投稿入口及核验日期。官网、投稿系统和数据库详情分别标注。教师可以按学科和收稿范围圈出候选期刊，学生可以按刊号和目录身份核对作业或申报所需的信息。
2. 建立期刊记录与目录记录之间的对应关系。每条目录记录保存目录名称、版本、生效时间、原文出处及认定等级，允许同一本刊同时关联多份目录。管理端输入发表年份和刊号后，先给出匹配的版本和原文位置。条款时间或刊物身份存在疑点时，显示「待人工复核」。
3. 补齐同一目录的多个版本后，按期刊身份对照新增、移出和等级变更。涉及评奖计分时，等取得适用年份的正式细则后，再录入作者顺序、署名单位、时间范围等条件，并保留每项判断的对应条款。

**验收办法。** 分别用一条多目录命中、一条仅收录于其他目录和一条刊名有变化的记录测试。每个结果都应能回到对应目录版本和原文；已知信息不足的项目应有明确待核项。

### 5. 用文章数据增加跨城市合作图层

**改进目标。** 现有连线表示苏大目录的收录关系。若要进一步观察学术交流，可以另建共著关系图层，比较期刊登记地分布与作者机构合作分布。

**操作步骤**

1. 选择一个学科和一个完整发文年份，从具备机构信息的公开文章元数据中取样。用 DOI 或稳定记录号去重，保留论文年份、公开作者机构原名和出处。对机构别名做归并，查证所在城市；多校区或不能确认的机构地址单列待核。
2. 在同一篇文章内，将已核验的不同城市两两配对，建立无向城市边。同一篇文章对同一城市对只计一次，边权为涉及该城市对的去重论文篇数。导出边时同时保留起终点、统计年份、篇数和支撑论文记录号。
3. 在地图上为「目录收录」和「跨城市合作」分别设置开关和图例。前者查看被收录的刊物登记在哪些省级地区，后者查看样本论文中的作者机构如何跨市合作。两张图比较时注明学科、年份、数据覆盖率及排除记录数。

**验收办法。** 用同时涉及苏州、南京和上海三个城市的测试记录检查是否生成三条无向边，再加入一条重复记录，检查边权是否保持不变。正式样本中抽查几条边，沿记录号回到原文核实两端机构及城市。
