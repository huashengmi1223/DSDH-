# 苏大期刊层级网络的空间分布

[空间人文 GIS 作业](苏大期刊层级网络_空间人文GIS作业.html)包含「空间图谱」「原六圈层」和「实验说明与发现」。空间图谱在原有学科和期刊等级的基础上增加地理位置。点表示省级登记地的代表城市或境外机构所在城市，线表示苏大目录收录关系，线宽随收录条目数增加，面用 5° 或 10° 经纬格网汇总条目数。第 6、7 章知识点、定位依据和结果解释见「实验说明与发现」。

原图的 889 条记录中，609 条已定位，280 条保留在「待定位」清单。境外另选 3 本期刊，用于展示城市尺度的定位方法。国内按省级登记地聚合，例如江苏条目统一显示在南京代表点。

## 运行与查看

用 Chrome 打开「苏大期刊层级网络_空间人文GIS作业.html」。图谱可离线查看，打开期刊官网和定位依据需要联网。

1. 在「空间图谱」中切换「国内」「境外」「全球对照」或「待定位」。也可以按目录、圈层、学科筛选，或直接搜索刊名。
2. 点击地图上的地点，符合当前筛选的刊名会围绕该点成环。期刊较多时，点「上一组」「下一组」翻看，或点「全部展开」后放大、拖动查看。点刊名可打开右侧明细，点圆心或「返回地图」可收起刊名环。
3. 用「点」「线」「面」开关查看不同图层。要复现说明中的格网对比，在「国内」视图选择「苏大目录」，分别查看 5° 和 10° 格网。

## 导出

页面下方的「导出点 GeoJSON」「导出线 GeoJSON」「导出面 GeoJSON」分别生成可导入 QGIS 的三个图层。坐标使用 WGS 84，顺序为经度、纬度。也可导出当前记录的 CSV。导出内容随当前范围和筛选变化，导出前可用「清除筛选」恢复所选范围内的全部记录。
